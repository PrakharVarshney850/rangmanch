# Moving the project to your laptop

How to get the Rangmanch site running on a different computer from scratch.

---

## 1. Install Node.js

The site needs **Node.js 20 or newer**. It was built and tested on **Node 24.19.0 / npm 11.17.0**.

1. Go to **https://nodejs.org**
2. Download the **LTS** version for your operating system
3. Run the installer and accept the defaults
4. Restart your terminal afterwards, or the `node` command will not be found

Check it worked — open **PowerShell** (Windows) or **Terminal** (Mac) and run:

```bash
node --version
npm --version
```

You should see a version number like `v24.19.0`. If you get *"command not found"*, close the terminal, open a new one, and try again.

---

## 2. Copy the project folder

Copy the whole **`rangmanch`** folder to your laptop — USB drive, OneDrive, Google Drive, WeTransfer, anything.

### Leave these out if they exist

| Folder | Why |
| --- | --- |
| `node_modules` | 500+ MB of downloadable packages — `npm install` recreates it |
| `.next` | Build cache, regenerated automatically |
| `out` | The built site, regenerated by `npm run build` |

Without those, the project is only about **2.6 MB**. With them it is over **530 MB**, so skipping them saves a lot of time.

> **Everything the site needs is inside this folder.** All logos, video posters and fonts are included. Nothing is fetched from Google Drive when you build.

---

## 3. Install the dependencies

Open a terminal **inside the `rangmanch` folder**.

On Windows, the quickest way: open the folder in File Explorer, click the address bar, type `powershell`, and press Enter.

```bash
npm install
```

This downloads the packages and takes 1–3 minutes on a normal connection. A few `warn` messages are normal — only `error` matters.

---

## 4. Run it

```bash
npm run dev
```

Then open **http://localhost:3000** in your browser.

Leave the terminal window open while you work — closing it stops the site. Press **Ctrl + C** in the terminal to stop it deliberately.

Edit any file and save: the browser updates by itself.

---

## 5. Build the version you upload

When you are ready to put the site online:

```bash
npm run build
```

This creates an **`out`** folder containing the finished site as plain HTML, CSS and JavaScript — about 66 files, 3.3 MB. That folder is what gets uploaded to your host.

To check it before uploading:

```bash
npm run preview
```

Open **http://localhost:4500**. This serves the real built files, exactly as a web host would.

See **[DEPLOY.md](./DEPLOY.md)** for putting it on your GoDaddy domain.

---

## All the commands

| Command | What it does |
| --- | --- |
| `npm install` | Download dependencies — run once after copying |
| `npm run dev` | Start the editing server at localhost:3000 |
| `npm run build` | Build the site into the `out` folder |
| `npm run preview` | Serve the built site at localhost:4500 |
| `npm run lint` | Check code style |
| `npm run typecheck` | Check for type errors |

## Editing the content

Almost all the text lives in two files, so you rarely need to touch the page code:

- **`src/lib/site.ts`** — brand name, tagline, phone, email, Instagram link
- **`src/lib/content.ts`** — services, verticals, case studies, brands, partners, stats, FAQ
- **`src/lib/showreel.ts`** — the video list

After editing, save the file and the browser refreshes on its own.

### Adding a video to the showreel

1. Upload the video to the Bharat Bass Festival Drive folder and copy its **file ID** — it is the long code in the URL:
   `drive.google.com/file/d/`**`1AbC...XyZ`**`/view`
2. Download a thumbnail for it:
   `https://drive.google.com/thumbnail?id=FILE_ID&sz=w1600`
   Open that in a browser, right-click, save. **Check the image is not plain black** — videos that fade in from black give an empty first frame. If it is black, pick a different video or grab a frame from elsewhere.
3. Convert it to `.webp` (https://squoosh.app is free and works in the browser) and put it in `src/assets/showreel/`
4. Add an entry in `src/lib/showreel.ts`, copying the format of the ones already there

The videos themselves always play from Google Drive — they are never copied into the project.

## If something goes wrong

**`node` or `npm` is not recognised**
Node.js is not installed, or the terminal was open before you installed it. Close the terminal, open a new one, try again.

**`npm install` fails**
Check your internet connection. If you are on a corporate network, a proxy may be blocking it — try a personal network or phone hotspot.

**Port 3000 is already in use**
Something else is using it. Run `npm run dev -- --port 3001` and open http://localhost:3001 instead.

**`running scripts is disabled on this system`** (Windows PowerShell)
Use `npm.cmd install` and `npm.cmd run dev` instead — adding `.cmd` bypasses the script-execution policy.

**The page looks unstyled or broken**
Stop the server with Ctrl + C, delete the `.next` folder, and run `npm run dev` again.

**Videos will not play**
Playback streams from Google Drive, so it needs an internet connection. Also confirm the Drive folder is still shared as *"Anyone with the link"*.
